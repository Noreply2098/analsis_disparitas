Tentang Regional Income Analysis

Sistem otomatisasi pengolahan data dan analisis disparitas pendapatan regional berbasis Python.

Profil Aplikasi

Regional Income Analysis (RIA) merupakan aplikasi berbasis web yang dikembangkan untuk membantu proses pengolahan data ekonomi regional dan menganalisis tingkat ketimpangan pendapatan antarwilayah.

Aplikasi ini menggunakan Python sebagai bahasa pemrograman utama, dengan metode Indeks Williamson untuk mengukur tingkat disparitas pendapatan regional.

Tujuan Pengembangan

  • Mempermudah proses pengolahan data ekonomi regional.
  • Menyediakan fitur import dan input data secara manual.
  • Menghitung tingkat disparitas menggunakan Indeks Williamson.
  • Menyajikan hasil analisis dalam bentuk tabel dan visualisasi.
  • Mendukung kebutuhan penelitian dan pembelajaran akademik.

Metode Analisis

Metode yang digunakan dalam aplikasi ini adalah Indeks Williamson, yaitu metode untuk mengukur tingkat ketimpangan pembangunan atau pendapatan antarwilayah dengan mempertimbangkan jumlah penduduk.

Indikator yang digunakan:

  • Nama Wilayah
  • Tahun Pengamatan
  • PDRB Per Kapita
  • Jumlah Penduduk
